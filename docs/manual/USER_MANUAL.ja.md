## 1. 起動方法・CLI モード・6 面ワークスペース

### エミュレータの起動

- **Windows（`x86_64` ポータブル版）**：
  - **`fuji-emulator-gfx100s.exe`**（同梱の `jdk\bin\java.exe` を自動検出し、ハイブリッド GPU ノート PC では NVIDIA/AMD 外部 GPU を自動選択する依存ゼロのネイティブランチャー）または **`start-gfx100s.bat`** をダブルクリックします。
- **Linux（`x86_64` ポータブル版）**：
  - **`./start-gfx100s.sh`**（`app-image` 版では **`./bin/fuji-emulator-gfx100s`**）を実行します。
- **ソースワークスペース（`JDK 25`）**：
  - `sh jvm.sh launch`（または `./gradlew :desktop:run --args="--home local/runtime --config local/runtime/config/emulator.yaml --auto-boot"`）を実行します。

主な起動オプション（ランチャーやスクリプトの末尾に追加可能）：

| オプション | 内容 |
|---|---|
| `--auto-boot` | ウィンドウ表示と同時にファームウェアを自動起動します（リリース版ランチャーでは既定で有効） |
| `--flash-dat <パス>` | 公式 `.DAT` ファームウェアを `flash/nor-flash.bin` へ書き込んで終了します |
| `--boot-rom` | 標準の Flash-Direct の代わりに、実験的な `bootrom/boot-rom.bin`（`PC = 0xFFF00000`）コールドブートを有効化します |
| `--realtime-pace` | アイドル時の仮想クロック（`54 MHz`）を実時間 1:1 にペーシングし、ホスト CPU 負荷を抑えます |
| `--nogui` / `--headless` | GUI ウィンドウを開かず、ターミナルコンソールと HTTP API のみで動作させます |
| `--no-console` | 対話型 `fuji> ` 標準入力コンソールを無効化します |
| `--debug` / `--log-level=<LVL>` | コンソール出力のログレベル（`TRACE`、`DEBUG`、`INFO`、`WARN`、`ERROR`、`OFF`）を指定します |

### コントロールセンターと 6 面カメラスタジオ

デスクトップ版を起動すると、**コントロールセンター**（`MAIN ENTRY`）と、個別に配置可能なカメラ各面のウィンドウが開きます：

- **上部ヘッダーバー**：
  - **Load Firmware / Pause / Resume**：状態を保持したまま 4 コア ARM の実行を一時停止・再開します。
  - **Flash**：GUI から `.DAT` ファームウェアの書き込み、64 MiB `.bin` NOR イメージのエクスポート／インポート、工場出荷時イメージの復元を行います。
  - **Lens Profile**：独立したフローティング **レンズ光学プロファイル** ウィンドウを開閉します。
  - **Controls**：**キーボードショートカット & ゲームパッド割り当て** ダイアログを開きます。
  - **Body / UI / Reload / Lang**：ボディ外観テーマ、UI 配色テーマ、外部テーマのホットリロード、表示言語を即座に切り替えます。
- **6 つのカメラフェイス（`GFX100S Original` レイアウト）**：
  - **背面（Rear）**：`1024×768` メインタッチパネル液晶（`LCDC1`）、EVF アイピース、フォーカスレバー（ジョイスティック）、リアコマンドダイヤル、`MENU/OK`、`DISP/BACK`、`PLAY`、`Q`、`AF-ON`、`AE-L`、消去ボタン。
  - **上面（Top）**：回転する `P/S/A/M/C1..C6` モードダイヤル、`STILL / MOVIE` 切換レバー、電源レバー & 二段式シャッターボタン、`Fn1`/露出補正ボタン、`DRIVE` ボタン、および **肩部モノクロサブ液晶（Shoulder Sub-LCD）**。
  - **前面（Front）**：G マウントバヨネット & ラージフォーマット CMOS / 装着レンズ前玉、フロントコマンドダイヤル、前面 `Fn2` ボタン。
  - **左側面（Left Side）**：開閉可能な防塵防滴カバー付きの 3.5mm マイク端子、3.5mm ヘッドホン端子、USB-C 端子、Micro-HDMI 端子。
  - **右側面（Right Side）**：デュアル UHS SD カードスロットカバー。
  - **底面（Bottom）**：NP-W235 バッテリー室カバー。
  - `Controls` タブで表示する面を個別に切り替えでき、**Arrange Windows** を押せば画面サイズに合わせて自動整列されます。

### フローティング EVF（`EVF Window`）と肩部サブ液晶

- **独立 EVF ウィンドウを開く**：背面の EVF ファインダー部をダブルクリックするか、`Controls` タブの **EVF Window (F8)**、または **`F8`** キーを押します。
- **最前面ピン留め対応**：`1280×960` の EVF 出力を拡大表示し、**Pin** ボタンで常に最前面（Always on Top）に固定できます。
- **アイセンサー（`F6`）と `VIEW MODE`（`F7`）**：
  - **`F6`** キー（または EVF ウィンドウ内のボタン）で、仮想 `TMD2772` 近接アイセンサー（`I2C1 @ 0x39`）の **接眼（Near）**／**離眼（Far）** を切り替えます。
  - **`F7`** キーで本体の **`VIEW MODE`** ボタン（`GPIO 7.6`）を押し、ファインダー／背面液晶の表示モードを切り替えられます。
- **肩部サブ液晶（Sub-LCD）**：**Top** ウィンドウ右側に配置され、シャッター速度・絞り・ISO・フィルムシミュレーション・ヒストグラム・撮影可能枚数を純正ファームウェアの描画そのままに表示します。

## 3. 物理ボタン・コマンドダイヤル・二段式シャッター・端子カバー・入力バインド

### マウスによる本体操作

- **背面タッチ液晶**：画面上の左クリックでタッチ AF・タッチシャッター・Q メニュー操作、ドラッグで再生画面のスワイプ送りや AF 枠移動が行えます。
- **モードダイヤル（`P / S / A / M / C1..C6`）**：ダイヤル上でマウスホイール回転、ドラッグ回転（1 クリック `-36°`）、右クリックによるスロット直接選択、または `Controls` タブから切り替えられます。
- **`S / C / M` フォーカスレバー & `STILL / MOVIE` レバー**：本体レバーのクリック・ドラッグ・ホイール回転で切り替えられます。
- **フロント／リアコマンドダイヤル**：ダイヤル上で**マウスホイール回転**または**左右ドラッグ**で 1 ノッチずつ回転し、**中央クリック**でダイヤル押し込み（`frontDialPress` / `rearDialPress`：ピント拡大や機能切替）を送信します。
- **二段式シャッター（`S1` 半押し / `S2` 全押し）**：
  - 本体のシャッターボタンを軽くクリックすると、確実に AF 合焦から 102MP 撮影まで完了するよう調整された **`650 ms` のシャッターパルス**が発生します。
  - 半押し（`S1`）と全押し（`S2`）を個別にコントロールしたい場合は、ボタンマトリクス、キーボードショートカット、またはゲームパッドのアナログトリガーを使用します。
- **同時押しコンボロック（Combo-Lock）**：
  - 複数ボタンの同時押し（例：`DISP/BACK` を押しながら電源 ON でファームウェア更新画面に入る操作など）を行うには、任意のボタンを **右クリック**、**`Shift + クリック`**、または横の **`🔓`** アイコンをクリック（あるいは **Combo-Lock Mode** を有効化）して押しっぱなし状態にロックします。解除はヘッダーの **Release All Keys** または **Unlock All** で一括解除できます。
- **開閉式端子カバー・スロット蓋**：
  - 左側面の端子カバー、右側面の SD カード蓋、底面のバッテリー蓋は左クリックで開閉アニメーションします。

### キーボードショートカット & マルチゲームパッド設定（`Controls`）

上部ヘッダーの **`Controls`** を押すと **Controls — Key & Gamepad Bindings** が開きます（設定は `<エミュレータフォルダ>/input-bindings.yaml` に保存）：

- **ファインダー用固定ファンクションキー**：
  - `F6`：EVF アイセンサー切替（接眼 ↔ 離眼）
  - `F7`：`VIEW MODE` ボタン押下
  - `F8`：独立フローティング EVF ウィンドウの表示／非表示
- **キーボードショートカット（初期状態は未割り当て）**：
  - コンソール入力中の誤爆を防ぐため、キーボードは初期状態で空になっています。
  - **Keyboard** 列をクリックし、任意のキーまたは修飾キー組み合わせ（`Ctrl`、`Alt`、`Shift`、`Meta`）を押すだけで全 35 アクション（`S1` 半押し、`S2` 全押し、`AF-ON`、`AE-L`、フォーカス前後、ズーム、前後・モードダイヤル、`MENU/OK`、`DISP/BACK`、`PLAY`、`Q`、方向キー、`Fn1/Fn2/Fn4` など）へ自由に割り当てられます。
- **ネイティブ XInput / evdev ゲームパッド対応**：
  - Windows（`XInput`）および Linux（`evdev`/`joydev`）で最大 4 台のコントローラーを接続可能（スティックデッドゾーン `0.10..0.50` 調整対応）。
  - **標準ゲームパッドプロファイル**：
    - **右トリガー（`RT`）二段式シャッター**：`25%` 以上（`RT ½`）で **`S1` 半押し（AF・測光ロック）**、`80%` 以上（`RT`）まで引き切ると **`S2` 全押しレリーズ**！
    - **`RB` / `LB` / `LT ½`**：`AF-ON` / `Q メニュー` / `DRIVE`
    - **右スティック（`RS`）**：左右 = **リアコマンドダイヤル**、上下 = **フロントコマンドダイヤル**、押し込み（`R3`）= **リアダイヤルプッシュ**
    - **十字キー & 左スティック（`LS`）**：4 方向キー + 押し込み（`L3`）= **フォーカスレバー押し込み**
    - **`A` / `B` / `X` / `Y`**：`MENU/OK` / `DISP/BACK` / `再生（PLAY）` / `消去（Delete）`
    - **`Back` / `Start`**：`VIEW MODE` / `Fn1`

### 3 モード絞りリング双方向同期（`A Auto` / `C Command` / `Manual F`）

電子接点付きレンズは `SPI0 LENSCOM` プロトコルを介してカメラ本体と双方向同期します：

- **`A Auto`（A ポジション）**：`P` / `S` モード時にカメラ側の自動露出がレンズ絞りを自動制御します。
- **`C Command`（C ポジション）**：ボディ側の**フロント／リアコマンドダイヤル**で F 値を変更します。
- **`Manual F`（手動絞りリング）**：レンズ鏡筒の絞りリングを直接回す操作を再現——**Aperture** スライダーを動かすと、カメラの背面液晶・EVF・肩部サブ液晶・AE 露出計の F 値がリアルタイムに追従します。

### 物理フォーカスモーター & エキスパート光学チューニング

- **リアルな AF 駆動速度**：**Realistic Focus Motor Travel** を有効にすると、DC モーターとリニアモーター（`LM`）の物理駆動速度差を再現します。テレメトリ欄には 35mm 判換算焦点距離、水平画角、過焦点距離、許容錯乱円（CoC）、被写界深度（DoF）がリアルタイム表示されます。
- **Advanced Optics（詳細光学調整）**：歪曲収差（`k1`/`k2`）、倍率色収差、軸上色収差（LoCA）、開放球面収差グロー、`cos⁴`・機械的周辺減光、フォーカスブリージング、T 値透過率、イメージサークル径、逆光フレア色、絞り羽根枚数（`5..11`）・円形度、口径食（キャッツアイ）、玉ねぎボケ、バブルボケ輪郭まで自在に調整できます。

## 5. ユニバーサル・マットボックス光学フィルタースタック

サイドバーの **MATTE BOX · FILTERS** または `Lens & Optics` タブ内の **MATTE BOX · OPTICAL FILTER RACK**（およびコンソール `/filter`・`/nd`）から操作します：

- **フィルター径の制約なし（ユニバーサル設計）**：本エミュレータは **物理的なフィルターねじ込み径（`ø62mm` / `ø77mm` / `ø82mm` など）の制限を一切設けません**。ステップアップリングを気にせず、すべてのレンズにすべてのフィルターを自由に装着できます。
- **最大 12 スロット重ね掛け & スイングアウェイ（バイパス）**：レンズ先端側（`#1`）から後端（`#N`）まで最大 12 枚を自由な順序で重ね掛け（例：`ND8 + ND64 = 9 EV`）でき、ワンクリックの **Quick Recipes** や、負荷ゼロでフィルター枠ごと退避させる **IN PATH / SWING AWAY** マスタースイッチを備えています。
- **内蔵光学フィルター要素**：
  - **ND フィルター（減光）**：`0.0..10.0 EV`（`ND2..ND1000`）の連続・段階減光。CMOS に入射する光量を物理的に減衰させるため、カメラ内の露出計やオートシャッター速度が正確に変化します（例：`ND8` で正確に `-3.00 EV`）。
  - **ハーフ ND（`Graduated ND`）**：空側の減光量（`0..5 EV`）、境界位置（Horizon）、ぼかし幅（Feather）、回転角を調整可能。
  - **ブラックミスト（`Black Mist`）**：ハイライトを滲ませ映画的なトーンを作るソフトフィルター（`1/8`〜`1` グレード）。
  - **クロスフィルター（`Star Cross-Screen`）**：点光源から `4` / `6` / `8` 本の光条（クロス効果）を発生させます。
  - **物理 UV フィルター比較（`UV Filter`）**：ナノマルチコート **Pro MRC**（透過率 `99.6%`）、単層コート **Standard**（`96.5%`）、ノンコート安物ガラス **Cheap Glass**（`89.5%`、強いフレア・点対称ゴースト・MTF 低下・緑かぶり）の描写差を比較できます。
  - **ボケ瞳マスク（`Bokeh Mask`）**：入射瞳に **`★5 星型`**、**`♥ ハート`**、**`⬡ 六角形`**、**`◎ リング`**、**`✦ カスタム`** の切り抜きマスクを挿入し、玉ボケの形状そのものを変化させます（`gf110` 開放 `f/2` + `scene://star-bokeh` でのテストが最適です）。
  - **Rescan Plugins** で外部 `filters/*.jar` やカスタム Vulkan `.spv` コンピュートシェーダを再起動なしで読み込めます。

- **`scene://star-bokeh`（*Point-Light Bokeh*）& `scene://bokeh-city`（*Night Bokeh City*）**：大口径レンズで手前 `1.35 m` のターゲットにピントを合わせることで、背景の点光源に美しい玉ボケ・星ボケ・口径食を描き出す専用シーンです。

### 2D 平面 & 外部ライブ入力（`2D` バッジ）

2D 入力時は `Lens & Optics` 内の **2D Planar Subject Distance** スライダーで被写体距離を指定してボケ量を調整できます：

- **静止画（`JPEG` / `PNG`）**：任意の画像ファイルやテストチャート（同梱 `test-qr.jpg` など）。
- **ローカル動画（`FFmpeg`）**：`.mp4` / `.mkv` / `.mov` ファイルのループ再生入力。
- **画面 / ゲームキャプチャ（`Screen / Game Capture`）**：`screen://primary`（プライマリ画面全体）や `screen://region/x,y,w,h?fps=24`（矩形領域指定）でデスクトップやゲーム画面を中判カメラ越しに撮影できます。
- **Web カメラ（`Webcam`）**：PC に接続されたカメラ（`webcam:default`）。
- **ネットワークストリーム（`RTSP / TCP / HTTP`）**：`rtsp://` カメラや `tcp://127.0.0.1:9555` ループバックフレーム入力。

## 10. 全二重ホストオーディオ I/O

**`Audio I/O`** タブ（またはサイドバーのクイックパネル／コンソール `/audio`）から、Windows `WASAPI` / Linux `PipeWire`・`PulseAudio`・`ALSA` 対応の 48 kHz 双方向オーディオを制御します：

- **出力（カメラ → PC）**：
  - シャッター音、AF 合焦音、操作音、セルフタイマー音、および `.MOV` 動画再生の音声を出力します。出力デバイスのホットスワップ、音量・ミュート、仮想 **3.5mm ヘッドホン端子（`GPIO 8.4`）** の挿抜切り替えに対応しています。
- **入力 & システムループバック（PC → カメラ）**：
  - `.MOV` 動画記録および画面上の L/R マイクレベルメーターへリアルタイムにステレオ音声を入力できます：
    1. **Input Off（入力オフ）**
    2. **Host Microphone（PC のマイク入力）**
    3. **Capture System Output / Loopback（PC システム音声のループバック録音）** —— PC 上で再生中の音楽やゲーム音声をそのままカメラの動画へダイレクト録音できます！
    4. **3D Scene Spatial Audio** —— `scene://milk-frog` など 3D シーンの同期音声を直接入力
    5. **Built-in 440 Hz Test Tone（440 Hz テストトーン）**
  - 入力ゲイン、入力ミュート、パススルーモニター、目標レイテンシ（`10..500 ms`）、仮想 **3.5mm 外部マイク端子（`GPIO 6.4`）** スイッチ、リアルタイム VU メーターを搭載しています。

## 11. パフォーマンス & Vulkan 1.1 GPU コンピュート設定

**`Lens & Optics`** タブ下部の **`GRAPHICS / VULKAN COMPUTE`**（`profile.yaml` に自動保存、コンソール `/gpu` 対応）で設定します：

- **計算バックエンド切り替え（`Auto` / `Vulkan GPU` / `CPU SIMD`）**：
  - **`Auto (Vulkan -> CPU)`** *（推奨）*：システムの `vulkan-1.dll` / `libvulkan.so.1` を動的ロードし、3D シーン描画・光学フィルター・2×2 ピラミッドボケ畳み込み・CMOS 読み出し・LiveView ISP デモザイク／ピーキングを GPU コンピュートシェーダで高速処理します。Vulkan 非対応環境では自動的にマルチスレッド `AVX2`/`AVX-512` CPU SIMD パイプラインへフォールバックします。
- **物理 GPU 選択とハイブリッド GPU ノートでの注意点**：
  - 複数 GPU 環境では **Vulkan GPU** ドロップダウンから使用する物理 GPU を明示選択できます。
  - **ゲーム連携時の同一 GPU 推奨**：GPU External Memory（`ExtMem`）によるゼロコピー連携を使う場合は、**ゲームが描画されているのと同じ物理 GPU** を選択してください（異なる GPU 間では自動的に共有メモリ経由へフォールバックします）。
- **プロファイラ & リアルタイムペーシング**：
  - コンソールの `tps` で実時間比（RTR）や有効 MIPS を確認でき、`profiler start` / `profiler stop` で詳細なサンプリングレポートを取得できます。ノート PC でアイドル時の発熱・ファン回転を抑えたい場合は **`--realtime-pace`**（または `configs/emulator.yaml` の `realTimePacer: true`）をご利用ください。

## 12. トラブルシューティング & ログファイルの正確なパス

### よくある症状と対処法

| 症状 | 原因と対処法 |
|---|---|
| **起動時にファームウェア導入案内が出る** | `flash/nor-flash.bin` が未作成です。[`FIRMWARE.ja.md`](../FIRMWARE.ja.md) の手順に従い、公式 GFX100S v2.13 `GXUP0004.DAT`（SHA-256: `ea997915ac5accc79699392b47909bb29506f66ec8d571e5804dd1fb0408fd12`）を選択してください。 |
| **Vulkan 状態が `Active: CPU Fallback` になる** | Vulkan 1.1+ ドライバ（`vulkan-1.dll` / `libvulkan.so.1`）が見つかりません。NVIDIA / AMD / Intel の最新 GPU ドライバ（Linux では `mesa-vulkan-drivers` 等）を導入してください。 |
| **ボタン操作が効かない** | コンボロック（`🔒 Locked`）でボタンが固定されていないか確認し、上部ヘッダーの **Release All Keys** を押してください。また電源レバーが `ON` であること、一時停止（**Pause**）中でないことをご確認ください。 |
| **動画再生で音が出ない** | **Audio I/O** タブで出力が有効かつミュート解除されているか、`runtime/media/ffmpeg`（Windows は `ffmpeg.exe`）が存在するか確認してください。 |
| **カメラ設定を完全リセットしたい** | カメラ内メニューの `リセット → 設定初期化` を実行するか、CLI から `--flash-dat GXUP0004.DAT --no-preserve-calibration` を実行し `runtime/compoments/power-peer/submcu-nvram.json` を削除してください。 |

### ログファイルの正確な出力先（バグ報告時は必ず添付してください！）

本エミュレータは ANSI エスケープコードを含まないプレーン UTF-8 ログ（ファイル側は常時 **`DEBUG`** レベル、および `WARN [FALLBACK][vulkan|audio|bootrom|OS-SCHED]` 診断を記録）を以下へ出力します：

- **Windows（`x86_64` ポータブル版）**：
  ```text
  <エミュレータ展開先フォルダ>\logs\latest.log
  ```
  *（`fuji-emulator-gfx100s.exe` と同じフォルダ内の `logs\latest.log`。前回以前のセッションは `<展開先>\logs\yyyy-MM-dd-N.log.gz` に自動圧縮保存されます。）*
- **Linux（`x86_64` ポータブル版）**：
  ```text
  <エミュレータ展開先フォルダ>/logs/latest.log
  ```
  *（`start-gfx100s.sh` / `bin/fuji-emulator-gfx100s` と同じフォルダ内の `logs/latest.log`。過去のログは `logs/yyyy-MM-dd-N.log.gz` に保存されます。）*
- **ソースビルド実行時（`sh jvm.sh launch` / `./gradlew :desktop:run`）**：
  ```text
  local/runtime/logs/latest.log    （または --home 指定先フォルダ内の logs/latest.log）
  ```
  *（`-Dfuji.log.dir=/任意のパス` で出力先を変更でき、`fuji> ` コンソールの `/log status`・`/log level DEBUG` で稼働中のログレベルも変更可能です。）*
