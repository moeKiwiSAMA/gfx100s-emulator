## Logical protocol spaces

Selectors use their own namespace and bit-width. They are not CPU byte addresses, do not allocate backing, and cannot grant MMIO access. Unknown selectors refuse.

| Logical space | Component / port | Selector bits / word bits | CPU physical base |
| --- | --- | --- | --- |
| rtc-power-register | rtc / rtc.registers | 7 / 16 | not assigned / not CPU-routable |

## Unassigned protocol request candidates

These namespaces record firmware requests only. Transport identity is not physical device ownership. They install no endpoint, CPU mapping or fallback and always refuse access.
